# Code Of Conduct

OES is an open-source project for people building and studying complex enterprise systems. We want contributors to be able to disagree about architecture, tradeoffs, and implementation details without turning collaboration into a hostile experience.

## Expected Behavior

- Be respectful and direct.
- Critique code, designs, and decisions rather than people.
- Assume contributors are trying to improve the project.
- Explain architectural concerns with evidence and references.
- Welcome questions from people learning the domain.
- Keep discussions focused on the project and its users.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Publicly sharing private information.
- Deliberate disruption of issues, pull requests, reviews, or maintainer workflows.
- Repeatedly ignoring maintainer guidance about project boundaries.

## Enforcement

Maintainers may remove comments, close discussions, request behavior changes, or restrict participation when conduct harms the project community.

If you need to report a conduct issue, contact the maintainers privately through the repository owner profile or an available project contact channel.
