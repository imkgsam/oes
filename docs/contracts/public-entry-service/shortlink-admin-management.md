# ShortLink Admin Management Contract

> 服务设计唯一真相源：[public-entry-service.md](/Users/acehood/Documents/GitHub/oes/docs/architecture/services/public-entry-service.md)。本文只描述 ShortLink admin management command/query contract，不重新定义 BusinessCard、Campaign、CRM 或 Barcode 边界。

## 1. Purpose

Defines Phase 1 management contracts for creating, updating, disabling, archiving, querying, and reporting ShortLinks.

Admin management is used by:

- tenant-web / Admin BFF.
- target owner modules such as BusinessCard.
- future public entry management surfaces.

## 2. Control Model

All admin management commands and queries require:

```json
{
  "tenantId": "tenant_001",
  "operatorContext": {
    "operatorAccountId": "acc_admin",
    "operatorOrgId": "org_001",
    "traceId": "trace_001"
  }
}
```

Rules:

- Public redirect is anonymous, but admin management is authenticated.
- Caller boundary must enforce permission-service authorization.
- Commands must carry audit metadata.
- ShortLink service does not own permission truth.

Suggested permission codes:

```text
public-entry.short-link.read
public-entry.short-link.create
public-entry.short-link.update
public-entry.short-link.disable
public-entry.short-link.archive
public-entry.short-link.stats.read
```

## 3. Shared Shapes

### 3.1 ShortLinkSummary

```json
{
  "id": "sl_001",
  "tenantId": "tenant_001",
  "displayName": "Zhang San Canton Fair Badge",
  "shortCode": "CF26ZS1",
  "publicUrl": "https://go.oes.com/c/CF26ZS1",
  "targetKind": "INTERNAL_REF",
  "targetType": "BUSINESS_CARD",
  "targetResourceId": "card_001",
  "targetUrl": null,
  "entryPurpose": "BUSINESS_CARD",
  "sourcePlacement": "EXHIBITION_BADGE",
  "campaignRef": "canton_fair_2026_autumn",
  "status": "ACTIVE",
  "expiresAt": null,
  "createdBy": "acc_admin",
  "createdAt": "2026-06-08T10:00:00Z",
  "updatedBy": "acc_admin",
  "updatedAt": "2026-06-08T10:00:00Z"
}
```

### 3.2 Status

```text
ACTIVE
DISABLED
ARCHIVED
```

Rules:

- `expiresAt` is nullable and evaluated separately from `status`.
- Expired `ACTIVE` links are unavailable publicly but do not require status mutation.

### 3.3 Target

INTERNAL_REF:

```json
{
  "targetKind": "INTERNAL_REF",
  "targetType": "BUSINESS_CARD",
  "targetResourceId": "card_001"
}
```

EXTERNAL_URL:

```json
{
  "targetKind": "EXTERNAL_URL",
  "targetUrl": "https://brand-site.com/products/ma3124"
}
```

Rules:

- INTERNAL_REF requires `targetType` and `targetResourceId`.
- EXTERNAL_URL requires `targetUrl`.
- EXTERNAL_URL must use `https` and must not use unsafe protocols.
- Phase 1 does not enforce allowed external domains.

## 4. CreateShortLink

Purpose:

- Create a ShortLink for either INTERNAL_REF or EXTERNAL_URL.

Request:

```json
{
  "tenantId": "tenant_001",
  "displayName": "Zhang San main business card",
  "target": {
    "targetKind": "INTERNAL_REF",
    "targetType": "BUSINESS_CARD",
    "targetResourceId": "card_001"
  },
  "entryPurpose": "BUSINESS_CARD",
  "sourcePlacement": "MAIN_PROFILE",
  "campaignRef": null,
  "expiresAt": null,
  "operatorContext": {
    "operatorAccountId": "acc_admin",
    "operatorOrgId": "org_001",
    "traceId": "trace_create_001"
  }
}
```

Response:

```json
{
  "shortLink": {
    "id": "sl_001",
    "tenantId": "tenant_001",
    "displayName": "Zhang San main business card",
    "shortCode": "CF26ZS1",
    "publicUrl": "https://go.oes.com/c/CF26ZS1",
    "targetKind": "INTERNAL_REF",
    "targetType": "BUSINESS_CARD",
    "targetResourceId": "card_001",
    "targetUrl": null,
    "entryPurpose": "BUSINESS_CARD",
    "sourcePlacement": "MAIN_PROFILE",
    "campaignRef": null,
    "status": "ACTIVE",
    "expiresAt": null,
    "createdBy": "acc_admin",
    "createdAt": "2026-06-08T10:00:00Z",
    "updatedBy": "acc_admin",
    "updatedAt": "2026-06-08T10:00:00Z"
  }
}
```

Rules:

- `shortCode` is generated by the service.
- Phase 1 does not support custom shortCode.
- Newly created ShortLinks default to `ACTIVE`.
- Create must write audit metadata.

## 5. UpdateShortLinkTarget

Purpose:

- Migrate a ShortLink target without changing public URL.

Request:

```json
{
  "tenantId": "tenant_001",
  "shortLinkId": "sl_001",
  "target": {
    "targetKind": "EXTERNAL_URL",
    "targetUrl": "https://brand-site.com/products/ma3124"
  },
  "reason": "Temporary redirect to brand site",
  "operatorContext": {
    "operatorAccountId": "acc_admin",
    "operatorOrgId": "org_001",
    "traceId": "trace_target_001"
  }
}
```

Response:

```json
{
  "shortLinkId": "sl_001",
  "publicUrl": "https://go.oes.com/c/CF26ZS1",
  "previousTarget": {
    "targetKind": "INTERNAL_REF",
    "targetType": "BUSINESS_CARD",
    "targetResourceId": "card_001"
  },
  "target": {
    "targetKind": "EXTERNAL_URL",
    "targetUrl": "https://brand-site.com/products/ma3124"
  },
  "updatedAt": "2026-06-08T11:00:00Z"
}
```

Rules:

- Public URL and shortCode must not change.
- INTERNAL_REF and EXTERNAL_URL may migrate to each other.
- Command must audit before / after.

## 7. ChangeShortLinkStatus

Purpose:

- Disable, enable, or archive a ShortLink.

Request:

```json
{
  "tenantId": "tenant_001",
  "shortLinkId": "sl_001",
  "targetStatus": "DISABLED",
  "reason": "Employee offboarded",
  "operatorContext": {
    "operatorAccountId": "acc_admin",
    "operatorOrgId": "org_001",
    "traceId": "trace_status_001"
  }
}
```

Response:

```json
{
  "shortLinkId": "sl_001",
  "previousStatus": "ACTIVE",
  "status": "DISABLED",
  "changedAt": "2026-06-08T11:10:00Z"
}
```

Rules:

- Supported target statuses: `ACTIVE`, `DISABLED`, `ARCHIVED`.
- Changing to `DISABLED` or `ARCHIVED` should require a reason at caller boundary.
- Status changes must audit before / after.
- `ARCHIVED` links should not be reused as active public entries without an explicit restore decision; Phase 1 may disallow `ARCHIVED -> ACTIVE`.

## 11. GenerateShortLinkQr

Purpose:

- Generate or download a basic QR image whose content is the ShortLink public URL.

Request:

```json
{
  "tenantId": "tenant_001",
  "shortLinkId": "sl_001",
  "format": "PNG"
}
```

Response:

```json
{
  "shortLinkId": "sl_001",
  "content": "https://go.oes.com/c/CF26ZS1",
  "format": "PNG",
  "downloadUrl": "https://app.oes.com/api/public-entry/short-links/sl_001/qr.png"
}
```

Rules:

- QR content must be the public URL.
- Phase 1 does not create QRCodeAsset.
- Phase 1 does not support template, logo, brand styling, print layout, or material management.

## 12. Error Semantics

Common errors:

- validation failure
  - missing required field
  - invalid target shape
  - invalid URL format
  - unsafe URL protocol
- not found
  - `shortLinkId` not found in tenant
- target type unsupported
  - INTERNAL_REF targetType has no registered resolver
- status transition not allowed
  - unsupported status transition, such as archived restore if Phase 1 disallows it
- permission denied
  - caller lacks required `public-entry.short-link.*` permission
- tenant mismatch
  - requested ShortLink does not belong to tenant context
