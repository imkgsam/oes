# OES 分阶段实施路线图

## 1. 路线图原则

OES 的实施路线必须遵循以下原则：

- 先冻结架构，再扩展功能
- 先做平台底座，再接入业务域
- 先打通主链路，再追求子模块深度
- 先建立治理与审计，再放开 AI 自动化

原因是：

- 企业级系统最大的风险不是“功能少”，而是“边界没定就并行实现”

## 2. 第 0 阶段：架构与规范

### 2.1 目标

- 建立全局统一设计总纲
- 明确系统上下文与领域边界
- 明确文档体系、治理规则与 ADR 机制
- 明确 IAM、租户、事件、AI 的基础边界

### 2.2 前置条件

- 无

### 2.3 交付物

- `AGENTS.md`
- `docs/architecture/*.md`
- ADR 清单
- 后续线程协作基线

### 2.4 依赖关系

- 这是所有后续阶段的前置

## 3. 第 1 阶段：基础平台能力

### 3.1 目标

- 统一 Gateway 角色
- 统一 Internal gRPC 契约策略
- 引入或明确 Event Bus
- 完成日志、追踪、配置中心、服务发现、调度、审计等横向能力基线
- 冻结 Notification 平台边界与第一阶段交互模式

### 3.2 前置条件

- 第 0 阶段完成

### 3.3 交付物

- 平台能力清单与基线实现
- 基础通信与观测规范
- 系统服务可复用接入模式
- `notification-service` 的架构边界与实施计划

### 3.4 依赖关系

- 为第 2、3、4 阶段提供公共基础

## 4. 第 2 阶段：身份与权限平台

### 4.1 目标

- 完成 Auth、Identity、Permission、Entity、Tenant / Org 的平台边界定义与能力闭环
- 打通 operator context 在系统中的传递方式
- 建立统一权限判定与租户隔离基线
- 完成 `auth-service -> notification-service` 的 OTP 通知协作边界

### 4.2 前置条件

- 第 1 阶段基础平台能力可用

### 4.3 交付物

- 稳定的 IAM 平台模型
- 稳定的 tenant / org 基础模型
- 可供业务域接入的身份与权限能力
- 可供 Auth 和后续业务域复用的通知平台接入模式

### 4.4 依赖关系

- 是所有业务域接入与 AI 接入的重要前置

## 5. 第 3 阶段：核心业务域逐步接入

### 5.1 目标

按照企业主价值链逐步接入核心业务域：

- CRM / SRM
- Product & BOM
- Sales Order
- Procurement
- Inventory / WMS
- MES
- APS
- Finance / ERP

### 5.2 推荐顺序

建议先从需求、订单、采购、库存开始，再进入生产与计划。

原因：

- 这样更容易形成“需求到执行”的主链路闭环
- 也更有利于后续 AI 在录单、补货、预警与排产上的接入

### 5.3 前置条件

- 第 2 阶段完成 IAM 与租户基础
- 第 1 阶段完成基础平台能力

### 5.4 交付物

- 核心业务上下文逐步落地
- 主链路事件开始形成
- 业务工具接口具备后续 AI 接入基础

## 6. 第 4 阶段：AI 增强能力接入

### 6.1 目标

- 建立 AI 模型接入层
- 建立知识层
- 建立工具层和受控 Agent 层
- 将 AI 逐步嵌入高价值业务场景

### 6.2 首批场景

- 智能问答
- 智能录单
- 智能邮件 / 消息处理
- 智能预警解释
- 智能排产建议
- 智能补货 / 采购建议

### 6.3 前置条件

- 平台级权限与审计可用
- 租户边界可用
- 业务工具接口稳定
- 知识接入边界明确

### 6.4 交付物

- AI 平台基础能力
- 首批业务增强场景
- AI 安全、审计、成本控制基线

## 7. 第 5 阶段：优化与治理

### 7.1 目标

- 性能优化
- 容量规划
- SLO / 告警优化
- 成本治理
- 租户分层策略
- 数据质量治理
- 架构执行一致性回顾

### 7.2 前置条件

- 平台、业务域与 AI 能力已经形成可运行闭环

### 7.3 交付物

- 更成熟的生产治理体系
- 架构优化建议
- 长期演进策略

## 8. 当前阶段最重要的结论

OES 当前最适合投入的工作，不是继续扩展业务实现，而是：

- 完成第 0 阶段文档与治理冻结
- 推进第 1 阶段平台基础能力统一
- 推进第 2 阶段身份与权限平台稳定

只有完成这三步，后续业务域与 AI 能力的接入才不会失控。
