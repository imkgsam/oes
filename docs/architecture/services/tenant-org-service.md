# tenant-org-service 职责卡

## 1. Purpose

`tenant-org-service` 是 OES 的租户与组织上下文真相服务，负责回答“这个租户内部如何组织、当前操作者处于哪个组织上下文、组织范围应如何被解析”。

## 2. Owns

- 租户边界与租户级组织语义
- `OrgUnit`、组织树与层级结构真相
- 组织节点类型、组织路径与上下级关系
- 账号 / 成员与组织节点的归属关系
- 当前可切换 `org context` 与组织范围解析所需事实
- 组织节点与法定主体的可选受控关联

## 3. Does Not Own

- 自然人或法定组织主体主数据真相
- 账号认证、会话与登录链路真相
- 角色、权限、policy 与授权判定真相
- 完整员工任职生命周期与人力资源真相
- 客户、供应商、订单、审批实例等业务资源真相

## 4. Core Responsibilities

- 提供租户内部组织树、部门、小组、分公司等组织结构治理能力
- 维护账号 / 成员到组织节点的挂靠、主组织与多组织归属能力
- 为 `permission-service`、`workflow-service` 与业务服务提供 org scope 解析基础
- 为 Gateway / BFF 与业务服务提供当前操作者可消费的组织上下文摘要
- 允许组织节点在必要时受控关联到现实世界的 `organization party`，但不替代主体主数据

## 5. External Interfaces

- 典型上游入口：`api-gateway`、`identity-service`、`permission-service`、`workflow-service`、业务服务
- 典型下游消费方：
  - 需要组织范围判断的授权链路
  - 需要组织归属、责任组织或审批路由的业务服务
  - 需要展示组织切换与组织树的 BFF / 前端聚合层

## 6. Upstream Dependencies

- `identity-service`
  - 提供账号、操作者与租户上下文事实
- `party-service`
  - 在组织节点需要关联现实世界法定组织主体时提供上游主体事实
- 未来 `hr-service`
  - 在员工任职与岗位分配能力冻结后，提供更正式的人力任职事实

## 7. Downstream / Published Facts

- 租户内部组织树与组织节点元数据
- 账号 / 成员的主组织与附属组织归属
- 当前账号可切换的组织上下文列表
- 组织节点祖先、子孙、同级与路径等范围解析事实
- 组织节点与法定组织主体之间的受控关联结果

## 8. Non-goals

- 不直接承接认证、会话、令牌或账号凭证逻辑
- 不直接拥有自然人 / 法定组织主体主数据
- 不把组织成员一律等同为员工
- 不直接拥有薪酬、考勤、绩效、招聘等 HR 语义
- 不在本服务内直接实现业务域自己的订单、客户、供应商或审批规则
