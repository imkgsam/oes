# OES Ideas Inbox

## 1. 目的

本文档用于记录随时出现、值得保留但尚未进入正式设计的灵感。

它的目标只有一个：

- 防止灵感丢失

这里记录的内容不是正式 feature，不直接进入实现，也不等于已确认要做。

## 2. 使用规则

- 适合“先记住，别忘了”的内容
- 不要求已经想清楚边界
- 不要求已经决定实现
- 如果某条灵感反复出现，或已经准备展开讨论，应迁入 `candidates.md`
