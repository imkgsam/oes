# V2 Delivery Package History

This directory is not an active V2 state source. Existing files are historical repository records and are handled under document-governance rules.

Current execution state lives only in owner task stable artifact roots:

- DO: `delivery-package.json` (Delivery Package, DP)
- CO: `aggregate-delivery-package.json` (Aggregate Delivery Package, ADP)

The PR body contains only a generated DP/ADP summary using every repository PR-template section. Completed evidence is a typed, exact-basis envelope; an ADP also binds the confirmed complete child roster and explicit external dependencies. Package cleanup reopens the trusted owner binding, rejects physical aliases or repository-contained packages, and verifies actual absence plus an empty repository diff.

See [document governance](../../governance/document-governance.md) and the [execution model](../../governance/codex-execution-model.md).
