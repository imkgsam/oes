# Permission 管理

更新时间：2026-03-19 10:19:56 +08:00

## 目标

维护全局 `Permission` 模型，并为角色管理和 Policy 管理提供稳定的权限基础对象。

## 设计决策

- `Permission` 是全局模型，不按租户复制。
- `Permission` 应保持编码稳定，不建议随意修改。
- 后续系统管理员专属接口面需要覆盖全局 `Permission` 管理。
