# 1.3 按用户 ID 查询用户记录

更新时间：2026-03-23 19:58:00 +08:00

## 本次目标

实现 `identity-service` 的按 `userId` 查询自然人身份闭环。

## 主要调整

- 为 `identity_service` gRPC 合约新增 `GetUserById`
- 新增 `GetUserByIdQuery` 与 handler
- `UserRepository` 与 Prisma 实现增加按用户 ID 查询
- gRPC controller 接入 `getUserById`
- 查询结果保持为最小 `UserSummary`

## 备注

本次不扩展账户、组织或租户信息，只提供自然人最小身份查询。
