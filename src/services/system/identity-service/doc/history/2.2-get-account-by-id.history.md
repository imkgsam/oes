# 2.2 按账户 ID 查询账户历史记录

更新时间：2026-03-24 10:18:00 +09:00

## 本次变更

- 新增 `GetAccountById` gRPC contract
- 新增账户最小详情领域模型 `AccountSummaryEntity`
- 新增 `GetAccountByIdQuery` 与 `GetAccountByIdHandler`
- 扩展 `AccountRepository`，支持按账户 ID 查询
- 扩展 `PrismaAccountRepository` 与 `IdentityQueryGrpcController`
- `displayName` 已正式由 `UserAccount.displayName` 承接

## 设计约束

- 只承接 `auth-service` 当前所需的账户上下文校验能力
- 不扩展到账户管理、组织归属、联系方式资产
- 不再使用 `Tenant.name` 临时承接账户展示名

## 验证要求

- `pnpm --filter @oes/common build`
- `pnpm --filter identity-service build`
