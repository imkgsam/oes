# 4.3 账户多组织归属记录

更新时间：2026-03-24 10:52:00 +09:00

## 本次目标

实现 `identity-service` 的账户多组织归属闭环，正式开放 membership 的增删查能力。

## 主要调整

- 为 `UserAccountOrgMembership` 增加 `relationType`
- 为 `identity_service` 新增 `AddAccountOrgMembership`
- 为 `identity_service` 新增 `RemoveAccountOrgMembership`
- 为 `identity_service` 新增 `ListAccountOrgMemberships`
- 新增多组织归属 command / query 与对应 handler
- 新增附属组织归属新增、删除、查询能力
- 当前保留主组织切换能力，并禁止直接删除主组织归属

## 备注

本次沿用 `IDN-ORG-02` 已落地的 membership 模型，把主组织与附属组织统一收敛到同一关系表。
