# 3.1 按租户 ID 查询租户记录

更新时间：2026-03-23 19:58:00 +08:00

## 本次目标

实现 `identity-service` 的租户最小信息查询闭环：按 `tenantId` 查询 `Tenant`。

## 主要调整

- 为 `identity_service` gRPC 合约新增 `GetTenantById`
- 新增 `TenantSummaryEntity`
- 新增 `TenantRepository`、`GetTenantByIdQuery` 与 handler
- 新增 Prisma mapper 与 repository 实现
- gRPC controller 接入 `getTenantById`

## 备注

本次不实现租户写操作，也不调整 `Tenant` schema，只提供最小查询能力。
