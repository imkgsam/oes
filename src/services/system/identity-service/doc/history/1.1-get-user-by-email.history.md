# 1.1 按个人邮箱查询用户记录

更新时间：2026-03-23 16:50:00 +08:00

## 本次目标

实现 `identity-service` 的第一个真实查询闭环：按个人邮箱查询 `User`。

## 主要调整

- 为 `identity_service` gRPC 合约新增 `GetUserByEmail`
- 新增 `GetUserByEmailQuery` 与 handler
- 新增 `UserRepository` 接口与 Prisma 实现
- gRPC controller 接入 `ValidatingQueryBus`
- 当前以历史 schema 中的 `User.email` 承接“个人邮箱”语义

## 备注

本次不调整 `schema.prisma` 字段命名，只完成查询闭环。
