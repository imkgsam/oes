# 2.1 按用户查询账户候选列表记录

更新时间：2026-03-23 17:20:00 +08:00

## 本次目标

实现 `identity-service` 的账户候选列表查询闭环，为 `auth-service AUTH-05` 提供真实上游数据。

## 主要调整

- 为 `identity_service` gRPC 合约新增 `GetAccountsByUserId`
- 新增 `AccountRepository`、账户候选实体和 Prisma 实现
- 新增 `GetAccountsByUserIdQuery` 与 handler
- gRPC controller 接入账户候选列表查询
- 当前以 `Tenant.name` 作为账户候选展示名的临时承接

## 备注

当前旧 schema 没有 `UserAccount.displayName` 字段，本次先用 `Tenant.name` 承接候选展示名，后续再做 schema 收敛。
