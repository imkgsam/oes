# 4.1 查询租户组织树记录

更新时间：2026-03-23 20:22:00 +08:00

## 本次目标

实现 `identity-service` 的组织树最小查询闭环：按 `tenantId` 返回租户组织树。

## 主要调整

- 为 `identity_service` gRPC 合约新增 `GetOrgTreeByTenantId`
- 新增 `OrgNodeEntity`
- 新增 `OrgRepository`、`GetOrgTreeByTenantIdQuery` 与 handler
- 新增 Prisma mapper 与 repository 实现
- gRPC controller 接入 `getOrgTreeByTenantId`
- 当前按 `order asc, createdAt asc` 生成稳定树结构

## 备注

本次不实现账户组织归属写操作，也不调整 `Org` schema，仅承接现有自关联树查询。
